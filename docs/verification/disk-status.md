# Live indexed-file conflict notices

Verified 2026-11-02. While a project is visible, Leaf checks its indexed disk paths every five seconds and on focus/visibility return. The read-only local status endpoint returns path/change metadata, never source text. Changes are reported before a save is attempted: a notice links the active path to **Review file versions** and other paths to **Check disk files**. Source is not reloaded or adopted automatically. Existing draft recovery remains independent, and editing can continue until the explicit comparison temporarily locks source.

A changed active path suspends normal autosave; visible unsaved text stays journaled and mirrored to SQLite. Its status reads **Unsaved**, including while a conflict blocks saving. An explicit Save still requires version review. Any observed changed project file marks the last successful PDF stale and explains that versions need review before compilation. Unavailable checks retain their last observation and mark the PDF uncertain rather than claiming it is current. **Retry disk check** shows a pending state and does not overlap requests. Guarded source/disk resolution still revalidates bytes/revisions independently of these notices.

## Observation boundaries

This is foreground polling of managed indexed paths, not an OS watcher or arbitrary-folder ownership. New unindexed files remain preserved and require the explicit discovery/import workflow. The backend coalesces observations for two seconds; generation changes invalidate that cache. Plain-path metadata fingerprints include inode/device, size, modification/change times, permissions and link count. Changed/initial fingerprints require existing guarded content reads and SHA256 comparison against indexed source; unchanged files reuse their last checked mark. Unsafe/unreadable paths remain flagged and are retried, never followed or executed.

Checks cover at most10,000 indexed entries and128 MiB of regular-file bytes, retaining only metadata for the four most recently observed projects. There is no independent background timer or persistent watcher. Hidden browser tabs pause requests and abort their current transport; failed checks back off for30 seconds, with explicit retry/focus available. A15-second client deadline releases hung requests and ignores late responses. Project/generation guards reject wrong-project or older results; disposal and generation updates invalidate in-flight responses. No status GET writes source, history, receipts, drafts or imports. Existing physical write guards remain authoritative between polls. This is not malicious-local-racer, power-loss or OS confinement certification.
