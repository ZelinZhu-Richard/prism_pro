## Execution boundary

The selected trusted TeX installation must contain executable `latexindent` or `latexindent.pl`. There is no fallback to another installation or automatic package installation. The formatter receives only `input.tex` copied into a unique derived snapshot, fixed `-d -s -c=<out>/ -o=<out>/formatted.tex` arguments, a credential-free compiler environment, and the existing macOS sandbox. Default-only `-d` ignores user/project YAML; no overwrite option or imported script is used. The process shares the compiler's independently owned supervisor, cancellation, parent-loss and process-group drain machinery. A 15-second formatter deadline does not change unlimited-by-default production compilation.

Input/output is valid UTF-8, at most2MiB, without NUL. Output must be a regular non-symlink/non-hardlink file; missing, empty-for-nonempty-input and invalid output cannot be applied. The captured executable/runtime identity is checked again before publishing output. Stop retires its explicit request ID even before creation is acknowledged. Lost responses require Check request or Stop before another run. Close cancels active work best-effort; source stays unchanged. Live process handles are never reconstructed from saved PIDs.

At most four processes, one per project, and40 completed in-memory results are retained. Jobs/results do not resume after restart. Derived snapshot artifacts remain on disk, as with compiler builds; no general cache-retention policy or arbitrary formatter safety certification is claimed. Diff presentation is bounded to800 rows/100ms with an explicit route to both complete source views. Unicode/source semantics are the installed tool's responsibility; the author reviews the literal result before Apply. This implementation currently requires macOS confinement.
