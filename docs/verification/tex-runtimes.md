## Reference and implemented behavior

The installed latexmk help confirms `-pdfps` for LaTeX/DVI/dvips/ps2pdf. Ghostscript documents [PostScript-to-PDF conversion](https://ghostscript.readthedocs.io/en/latest/Use.html#convert-a-postscript-document-to-pdf), and [Homebrew's formula](https://formulae.brew.sh/formula/ghostscript) supplies `gs` and `ps2pdf`. Those tools are now installed here. Earlier missing-tool preflight evidence remains valid: an incomplete runtime rejects before creating a job, without substituting another engine/runtime.

Selected runtime IDs persist separately from source/history. Old clients that omit the new field preserve an existing pinned choice; copies/new/template projects and template previews use System. Manual Type previews inherit the current choice. Each build records resolved version/path/fingerprint and rechecks tool identities before promotion. New-job SyncTeX uses its recorded installation; missing or changed tools require recovery. Older jobs without recorded runtime metadata retain their legacy navigation behavior and are labelled as such. Source ZIPs exclude runtime/application metadata.
