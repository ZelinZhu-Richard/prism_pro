# Compile options and generated-file verification

Verified 2026-11-01 using independent synthetic projects. The owner chose **Stop on first error** as the default. Normal/Stop is also the fallback for older projects/builds. This batch adds compiler choices and output inspection; the broader local-first Overleaf comparison remains active.

## Reference behavior and implementation choices

Overleaf documents [Normal/Fast draft and continue/stop modes](https://docs.overleaf.com/getting-started/recompiling-your-project) and [generated-file access](https://docs.overleaf.com/navigating-in-the-editor/generated-files). Prism implements the local operations using installed tools and immutable build snapshots. Revision-bound option saves, reviewed ZIP collision consent, frozen expiring download receipts and explicit recovery are Prism implementation choices. The fourth [LaTeX engine and TeX distribution/version selection](https://docs.overleaf.com/getting-started/recompiling-your-project/selecting-a-tex-live-version-and-latex-compiler) remain open.

Normal/Stop is the default, including copies and new/template projects. These per-project choices are outside source ZIPs and history; template previews use defaults, while Manual Type previews inherit current choices. Fast draft passes fixed draft options to standard graphics packages. Custom graphics and per-image overrides may behave differently. Continue uses latexmk's force-processing flag so all three supported engines can attempt a PDF despite source errors. Such a build remains **failed**, its PDF is labelled **PDF with errors**, and it never replaces the last successful job. Stop/fatal/cancel falls back to the last successful PDF. Both ordinary and isolated AI draft PDFs display mode/error labels.

Preparing freezes the reviewed ZIP. The native connected HTTP link stays in the dialog with **Prepare ZIP again**, **Change selection** and **Close**. Clicking it leaves **Download requested**, without claiming an observed save. Links expire after 15 minutes or restart; memory is bounded to four archives/200 MiB.

The exact UI-prepared link was retrieved over loopback HTTP into ignored `data/verification/build-tools-http-delivered.zip`: **61,249 bytes**, SHA-256 `65ef1fad3b1bfa6eb73c625fa806b337b9c5210b61e7891d431343a229686076`. Its 16 entries match the reviewed source/output bytes and directories, including an empty folder, binary image, nested source, bibliography and consented archive-only `main.log` replacement. Report: `build-tools-http-delivery.json`. This proves the link's HTTP payload, **not** browser-native saved-file delivery. The IAB file-link observer stalled and returned no artifact; no native save event or saved-file path is certified. No personal-browser fallback was used.

Text preview is full strict UTF-8 without NUL, up to 512 KiB. Downloads/ZIPs are bounded to 100 MiB, with 5,000 entries per source/output group. Supporting source is the selected build's snapshot, not current editor content. Source/output path replacement requires consent and affects only ZIP bytes. Symlink/hardlink/unsafe or changing files reject access. Credentials, app chats, history and review metadata are excluded. Imported configuration/scripts remain unexecuted; shell escape, timeout, environment isolation and macOS sandbox constraints remain in force.
