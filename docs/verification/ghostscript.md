# Ghostscript package check and installation

The owner explicitly authorized installing Ghostscript through Homebrew **after checking its security and validity**, on 2026-11-01. This authorizes the normal package/dependency writes outside the project workspace; evidence remains inside Prism. No Biber or additional TeX distribution was installed.

## Checks before installation

- The [official release page](https://www.ghostscript.com/releases/index.html) and [Homebrew core formula](https://formulae.brew.sh/formula/ghostscript) both identify stable **10.08.0**. The formula is active, not disabled/deprecated, uses the Artifex source release, and defines no background service or post-install step.
- The reviewed [pinned formula](https://github.com/Homebrew/homebrew-core/blob/115fd215603c89cd83031ffd2142489b46537187/Formula/g/ghostscript.rb) matches Homebrew API's Ruby-source SHA-256 `2d6606514ac36c06fd4b00141ba01bfc2d4d83fc2318c0cdaa022c8187e9a62b`. Its upstream source archive checksum is `94943e3c4adb7115d132b3c28b913672f2e62e6a9d802f7e754e716b1634174a`.
- The [vendor's fixed-CVE table](https://www.ghostscript.com/releases/cve/index.html) lists the recent 2026 fixes in 10.08.0. The [Debian security tracker](https://security-tracker.debian.org/tracker/CVE-2026-101258) identifies two commits for CVE-2026-101258. GitHub comparisons independently confirmed **both are ancestors of the actual ghostpdl-10.08.0 tag**, with zero commits behind: [procedure-stream fix](https://github.com/ArtifexSoftware/ghostpdl/compare/9d8b70ad1301c9993155dcf53401df3eac14fa4f...ghostpdl-10.08.0), [shading fix](https://github.com/ArtifexSoftware/ghostpdl/compare/3d8a1db60895493d73aeef89903d34da9837bc0a...ghostpdl-10.08.0). This resolves ambiguity from later advisory publication dates without assuming that a higher version number alone proves a fix.
- Before installation, the downloaded ARM64 Golden Gate Homebrew bottle (42,879,919 bytes) was independently hashed and matched the official API/formula SHA-256 `20d8eff70c436899114af3b971cc0108a63a1c086da53e933802ddd33f6cf283`.
- Ghostscript and conflicting `gambit-scheme`/`gerbil-scheme` formulas were absent in the initial inventory. The installation plan was reviewed before installation.

## Installation and validation

Installed the stable Homebrew core **bottle**, with automatic update, analytics, cleanup and unrelated installed-dependent repair disabled. The plan required eleven new dependencies and fifteen dependency upgrades. The exact execution log and before/after inventory are retained; the inventory also gained a libpsl entry with an older receipt, absent from this install log, so that catalog difference is not attributed to this command. Existing older dependency kegs were retained; no package removals occurred.

`gs --version` reports **10.08.0**. The installed executable is native ARM64 at `/opt/homebrew/Cellar/ghostscript/10.08.0/bin/gs`; `gs` and `ps2pdf` are available through `/opt/homebrew/bin`. `codesign --verify` passes and `brew linkage --test ghostscript` exits successfully. Signature consistency is not independent publisher identity: the official source/formula/registry and checksum checks establish the package provenance used here. Homebrew automatically enabled its developer mode for the linkage check; that setting was immediately restored to off afterward.

Prism now discovers `gs` and `ps2pdf` in both System and the pinned TeX Live 2026 Basic identity. It still excludes API credentials and user TeX overrides from compiler environments, disables shell escape/imported compiler configuration, sets `GS_OPTIONS=-dSAFER`, and applies its own macOS sandbox. A separate macOS sandbox remains necessary because Ghostscript's internal SAFER mode has had bypasses.

The full real verifier passed all four engines. Detailed fourth-pipeline evidence and the bounded resolved finish verdict are recorded in [the runtime report](tex-runtimes.md). It includes an actual failed outside-file read using a synthetic canary. This check does **not** prove the software free of unknown vulnerabilities or constitute a complete source/binary/dependency security audit. Process cleanup after an abrupt backend exit remains a separate [confirmed reliability gap](compiler-owner-exit.md).
