# Saved-chat search

The local worktree adds literal search over this project's saved conversation titles, user prompts and assistant replies. A turn matching both prompt and reply appears once, with its prompt excerpt preferred. Titles precede message hits; each group is newest first. A match opens the exact saved turn, including turns outside the latest 20. Earlier/Newer use scoped row cursors in both directions, and Return to latest leaves the search view. Archived messages are searched separately and require the explicit Restore & open action.

Search is case insensitive using JavaScript lowercasing. It is not regex, accent folding, canonical Unicode normalization, fuzzy or semantic search. LaTeX punctuation and one-character queries are literal. Only title/prompt/reply fields are searched: unsent drafts, source snapshots, proposed insertions, tool payloads, settings and private native-session identifiers are excluded. Snippets retain original spelling/Unicode and render through React text nodes, with no HTML interpretation.

Read-only SQLite workers have empty environments, a 256-MiB JavaScript heap limit, a two-second timeout and at most two concurrent searches. Queries accept 1–200 Unicode code points and reject controls/invalid UTF-8 round trips. A page returns at most 20 hits and a query/project/archive-bound cursor. Captured maximum row IDs exclude newly appended turns/conversations from subsequent pages. Existing saved messages/titles can change between pages; Refresh searches current saved data. No search index or additional database migration is required. The worker never initializes Store or writes to the database.

## Verification

**525 deterministic tests** and the production TypeScript/Vite build pass. Eight new tests cover literal punctuation, Unicode/case snippets, privacy, scope/origin validation, title/message pagination, 51-turn insertion stability, archive neutrality, restart, around/before/after navigation, invalid cursors, concurrency/timeout/shutdown and a **10,000-turn service fixture**. The large fixture verifies bounded response size, not browser performance at that history size. Vite retains its existing chunk-size advisory.

Built-in-browser checks used only the isolated synthetic server on 5173; the owner server on 4317 was untouched. The fixture contains 65 methods turns, a separate failed/partial bibliography reply, an archived discussion and another project. Checks reached turn 3 directly, paged Earlier to turns 0–2, returned with Newer, loaded 40 of 64 search matches, found Unicode text, switched archive scope, restored and opened an archived match, and retried both a failed search and a failed exact-turn load. Keyboard Enter focused the matching article. Unsent bibliography text survived server restart and selecting another match; a methods draft survived archive restoration/navigation. Search input and snippets remain contained in the 185px sidebar at the narrow test width. The existing editor shell requires horizontal scrolling below 650px; this change does not establish a full mobile layout.

A pre-generation audit confirms exact source files, checkpoint history, saved turns and conversation metadata during search-only checks: `data/verification/chat-search-neutral-audit.json`. Search caused zero generations. After the separate explicit archive restoration, one deterministic Manual Type request reused the methods conversation. Its reviewed draft started only after approval, paused, allowed read-only note inspection, rejected a keyboard edit there, disabled match-opening and compilation while busy, resumed at Instant, and used cross-file Undo to restore exact original main.tex and notes.tex bytes. Final fixture totals are 68 saved runs, three conversations, main-project generation 3/history 3, and the independent project remains generation 0/history 1. No provider or native CLI was contacted and no paid request occurred. Audit: `data/verification/chat-search-final-audit.json`.

Two bounded builder inspection rounds retained dark/light, default/expanded assistant, narrow archive/match and failure evidence in `.impeccable/review/chat-search/`. The second batch folded the search notice into the existing navigation, removed its duplicate floating latest control, and retained full-contrast archived excerpts. The once-only static detector reports no nonadvisory findings, with the intentional 16px narrow input size as its single advisory. The fresh finish reviewer returned **ship**, with no material fixes, at `.impeccable/review/chat-search/finish-review.md`. This verdict covers the bounded search extension, not computed contrast, motion, full mobile layout or overall parity. Broader parity and Ghostscript-dependent fourth-pipeline verification remain open. This batch is local and unpushed.
