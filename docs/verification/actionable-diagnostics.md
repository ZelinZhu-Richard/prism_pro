## Boundaries

Help is a conservative catalog for recognized messages, not TeX expansion or a guarantee about the underlying cause. Installed/generated-file locations are not invented as editable project links. Locations in old logs describe their captured build; current markers are withheld when evidence is stale. Source-only/newer-generation and unobserved-disk suppression is deliberately conservative. Source links preserve existing conflict/recovery requirements.

The informational parser does not turn every engine banner or font-loading line into a diagnostic. Full output remains available for unsupported formats. Live Biber, full mobile-editor acceptance, OS-disconnected/cold-cache installation, arbitrary-folder ownership, native packaging and broad security/accessibility certification remain separate. No private paper, owner project, live API/CLI request or owner-server restart was used. Restart the local app when convenient to load the new backend parser and browser bundle.
