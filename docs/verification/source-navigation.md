# Local source navigation — 2026-11-02

Leaf now exposes the [read-only navigation engine](source-navigation-engine.md) through **Go to definition** (`F12`) and **Find references** (`Shift+F12`) in Code view and the command palette. Place the caret in a literal command, environment name, label or citation key. The existing chooser lists paths, lines, columns and source excerpts, supports filtering and native arrows/Enter/Escape, and keeps duplicate definitions explicit. Active-buffer matches are identified separately. Refresh, index notes and recoverable errors remain in the chooser.

## File safety

Same-file navigation validates the complete visible text hash and exact spelling, then selects the passage without saving, reopening or changing its Undo group. Cross-file navigation verifies the target, uses the existing guarded preflight save/open flow, verifies the fetched candidate again and selects only after the editor is ready and the chooser has closed. A stale result requests Refresh. Failed saves retain the exact source draft; closing a pending lookup/open cancels its operation and ignores late results. Queries and source opening have independent 15-second recovery deadlines. Read-only agent ownership permits browsing and selection while source edits remain blocked.

## Installed TeX definitions — 2026-11-06

**Go to definition** also checks `.sty` and `.cls` files listed in the last successful build’s recorder, within the currently selected TeX Live distribution. Project and active-buffer results appear first. **Installed TeX** entries open a highlighted, read-only excerpt with the runtime, package path and exact line. Escape returns focus to the source editor. Opening an excerpt does not save the current draft or add a project tab. If source has changed since compilation, the chooser identifies the earlier build.

Leaf accepts only safe paths under the selected distribution’s `tex/` directory. It rejects outside paths, symlinks, hard links, nonregular files and invalid UTF-8. Work is bounded to a 2 MiB recorder, 128 recorded package paths, 1 MiB per file, 8 MiB per lookup and 2,000 combined results. Opening a result rechecks the project, runtime, current successful build, recorder membership, source hash and literal location. A new build or changed installed file makes an old result stale.

The recorder supplies candidate files. Leaf scans for literal declarations and shows duplicates. TeX expansion, dynamic names and resolution of the active macro definition remain outside this lookup. **Find references** searches the project. This implementation recognizes `\let` alias operands so they cannot hide later declarations in a package or a project file. Configured personal packages use the matching [build snapshot](tex-packages.md#personal-tex-trees--2026-11-06) for read-only definition excerpts.
