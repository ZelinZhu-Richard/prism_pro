# Code environment helpers

Verified 2026-11-02. Code view now marks literal same-file `\begin{name}` / `\end{name}` pairs when a caret is in either command. Matched commands use the existing selection role and underline; unmatched commands use a wavy danger underline with a descriptive title. **Cmd/Ctrl+Shift+\** jumps to the mate, extending CodeMirror's existing bracket-navigation shortcut; outside an environment it retains the incumbent bracket handler. **Go to matching environment** is also discoverable in the command palette and Help. Read-only matching/navigation does not change source.

With the default Code keymap, Enter after a standalone unmatched begin line inserts an indented body and end in one isolated editor transaction. Complete optional/required arguments are supported. Existing matched ends, prose/selection/mixed cursor locations and read-only source fall back to normal handling; compatible multiple cursors close independently. The current indent unit is used. Undo removes the generated body/end together while retaining the typed begin; Redo restores it. Programmatic edits, AI streams, paste and loaded snapshots do not invoke the Enter helper. Vim/Emacs retain their native Enter bindings.

**Settings → Editor → Close LaTeX environments on Enter** persists an independent validated boolean, enabled for legacy/default settings; disabling it keeps highlighting/completion available. No source, theme, saved provider or existing keyboard setting is migrated. Environment-name completion offers common names, declared names and other existing begins in the current file. End-name completion offers currently open literal environments. Accepting an option replaces the name/suffix and preserves the brace; it does not insert a second environment. Names that require packages do not imply those packages are installed.

## Scope and limits

The bounded scanner skips comments, escaped control sequences, inline `\verb`/`\verb*`, listed raw environments, and standard LaTeX/xparse/primitive macro-definition bodies. Raw environments include verbatim/Verbatim variants, lstlisting, minted, comment, filecontents variants, luacode variants and pycode. This is conservative lexical assistance, not TeX execution: arbitrary macros, catcodes, conditionals and all third-party inline literal commands are not expanded or fully understood. Environment names use a literal ASCII-leading80-character grammar; dynamic names and cross-file begin/end pairs are outside scope.

Matching/automatic closing stop beyond1,048,576 UTF-16 code units,20,000 environment tokens or256 nesting levels. Normal editing continues. The index is rebuilt on source changes and reused for selection-only highlighting/navigation; no worker or release-scale performance certification is claimed. Helpers are attached to `.tex`, `.sty` and `.cls` Code files; Visual projection retains its existing behavior. Broad package completion and definition/reference navigation remain separate P0 work.
