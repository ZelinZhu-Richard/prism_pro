## Reference behavior and local choices

Overleaf documents [creating colored tags and filtering projects](https://docs.overleaf.com/managing-projects-and-files/organizing-projects-with-tags/creating-a-new-tag), [renaming/recoloring tags](https://docs.overleaf.com/managing-projects-and-files/organizing-projects-with-tags/changing-the-name-or-color-of-a-tag), [tagging selected projects](https://docs.overleaf.com/managing-projects-and-files/organizing-projects-with-tags/adding-tags-to-your-projects), [archive/Trash and multi-project recovery](https://docs.overleaf.com/managing-projects-and-files/archiving-deleting-and-leaving-projects), and [one ZIP containing source ZIPs for selected projects](https://docs.overleaf.com/managing-projects-and-files/downloading-a-project). Prism independently implements those local organizing actions. Recoverable tag removal, atomic reviewed batches, signed retry journals and preserving archive status through Trash/restore are Prism recovery choices; these sources do not establish identical recovery internals or tag removal semantics.

Tags use nine color presets, a native color input and explicit HEX/RGB fields, with user color limited to small markers beside readable names. Tags can apply to several projects, several tags can be added/removed in one operation, and unrelated memberships remain. An archive hides projects from the normal/recent lists while leaving source editable and compilable. Tag filters include archived projects with explicit markers; tag counts exclude project Trash. Removed tags retain memberships. There is no automatic purge or permanent deletion.

## Boundaries

Library mutations accept 1–100 distinct projects, 1–32 selected tags and at most 32 active tags per project. There are 100 active/500 retained tags. ZIP export accepts up to 20 active/archived projects, 100 MiB uncompressed source and 10,000 entries; source edits invalidate a captured export generation. Compiled PDFs, source history, app chats/review and backend credentials remain separate. Committed metadata/journals survive restart; unsent fields and pending Retry IDs live in modal memory. Archive/tag edits are source-neutral; Trash waits for AI/compiler ownership to finish. No online service, new dependency, TeX installation, full distribution picker or source-history pruning was added.

The static detector ran once on changed targets and fell back to regex because optional parser modules were unavailable. It reported one intentional 16px narrow-input advisory and no warnings. It did not evaluate computed contrast or selector behavior. The first finish review requested two material fixes: recoverable download handoff and named busy-project context. After one correction batch and validated recaptures, the same reviewer scored both **resolved**, with **ship** covering those fixes only. The reviewer reopened all 18 current captures and checked the delivered ZIP hash; it did not rerun tests, browser or detector. Native color-popup interaction, exhaustive keyboard/assistive-technology behavior, all loading/empty/limit compositions, motion and extreme-content performance remain outside visual certification. Full parity is not claimed.
